# Hello Full Stack

This is my first full stack JavaScript starter project. The Node.js script gets user data from the internet, saves it in a file, reads it back and shows it.

## Project Setup
1. Install Node.js
2. Download the project: `git clone <your-repository-link>`
3. Open the folder and run: `npm start`

## Full Stack Structure
- **Front-end:** will be built in the next chapters.
- **Database:** MongoDB will be added later. For now the data is saved in `users.json`.
- **API:** data comes from jsonplaceholder using `fetch()`.

## Things used
ES6+ modules, async/await, fetch, fs module, arrow functions, destructuring, template literals
